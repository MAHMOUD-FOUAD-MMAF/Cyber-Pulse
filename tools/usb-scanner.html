💾 ماسح أجهزة USB

فحص أجهزة USB الخارجية واكتشاف الملفات الخطيرة والتهديدات المحتملة

📺 الفيديو التعليمي

🎥 فيديو تعليمي – شاهد طريقة فحص أجهزة USB واكتشاف التهديدات.

🤔 ما هو ماسح USB الأمني؟

هي أداة تقوم بفحص أجهزة التخزين الخارجية للكشف عن الملفات الضارة أو المشبوهة. تعتبر أجهزة USB من أكثر وسائل نقل العدوى شيوعاً.

⚠️ تحذير أمني: لا تقم أبداً بتشغيل أي ملف من USB غير موثوق قبل فحصه.

🖱️ كيف تستخدم الأداة؟

  1. ابدأ المراقبة: اضغط على ▶ START
  2. أدخل جهاز USB: قم بتوصيل الفلاشة أو الهارد الخارجي
  3. انتظر الاكتشاف التلقائي: ستظهر معلومات الجهاز
  4. راجع النتائج: سيظهر جدول بجميع الملفات مع تصنيف المخاطر
  5. اتخذ إجراء: حذف، عزل، أو تجاهل الملفات الخطيرة

📋 ملاحظات مهمة

  • ✅ Windows فقط: الأداة تعمل على نظام Windows فقط

  • ✅ الفحص التلقائي: عند توصيل USB بسعة كبيرة قد يستغرق الفحص عدة دقائق
